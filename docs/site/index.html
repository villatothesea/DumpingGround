01现实 / REALITY

删除一个文件，空间立刻回来。
海边的垃圾，没有这样的回收站。

在电脑里，垃圾是一个个能选中的文件：选中、删除，空间还给你。在海边，垃圾被浪推上沙滩，被日晒碎成更小的碎片，又被下一次涨潮带回海里。没有回收站，也没有撤销。

清理的速度，永远追不上它们被丢下的速度。所以真正有用的事，是让它们少一点被丢下。

02隐喻 / METAPHOR

一个软件，只是一个比方。

DumpingGround 原本是一个 Windows 小工具，帮人看清电脑里到底堆了些什么。把它放在这里，是想借它说一件事：我们愿意定期清理自己的电脑，为什么不能用同样的心思，对待海洋？

软件的图标，来自 FIG.01 里那座打包的垃圾堆：山顶插着一面旗。
旗插下去，意思是：这座山，我来接管。

04行动 / ACTION

没有那个按钮，但有几件今天就能做的小事。

  • A.01
    少用一次性的东西自带水杯和布袋，拒绝不需要的吸管与包装。少一件，就少一件漂向海里的可能。
  • A.02
    垃圾留在该去的地方海里的塑料，大部分先经过河流。你家门口那条小河，终点也是海。
  • A.03
    走一趟海边，带走几件垃圾参加本地的净滩活动，或者只是散步时多弯几次腰。
  • A.04
    买得少一点，用得久一点过度包装、用完即弃，都是从源头流出来的垃圾。
  • A.05
    把这件事说出去转发这个页面，把歌分享给一个人。让更多人知道：这个按钮不存在。
