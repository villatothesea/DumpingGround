常见问题

需要安装吗？

不需要。下载后双击 exe 即可使用，删除文件即完成卸载。

需要管理员权限吗？

不需要。进程查看、普通目录和盘符扫描都能用。以管理员身份运行时，NTFS 整盘扫描可使用 MFT 快速路径；权限不足会自动回退到普通目录遍历。

它会自动删除我的文件吗？

不会。磁盘分析是只读的，你可以一键定位到资源管理器自行处理。结束进程、卸载软件、禁用启动项都会先弹出确认。

会联网或上传我的数据吗？

不会。所有数据都在本机处理，应用没有联网功能。

扫描结果准确吗？

同时提供“占用空间”和“逻辑大小”两种口径，硬链接的占用空间只计一次。扫描的是运行中的文件系统，不是一致性快照，所以结果可能与卷已用空间略有差异。
